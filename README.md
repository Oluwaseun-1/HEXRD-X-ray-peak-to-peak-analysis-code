# HEXRD-X-ray-peak-to-peak-analysis-code
This repostory contains an algorithm to perform a peak-to-peak analysis  of X-ray profile obtained from X-ray diffraction. Peak-to-peak analysis allows to analyse individual spectrum/peak on a X-ray diffraction spectral. 

The code performs Pseudovoigt fitting on each profile in a pattern and the 
the following can be obtained from each individual spectrum:
(1) I - maximum intensity 
(2) 2θ - radial position of maximum intensity 
(3) FWHM
(4) d-spacing 


It was developed by Muritala Oluwaseun Arowolo during his PhD work at the 
University of Toulouse, Toulouse France within two CNRS research laboratories:

a) CIRIMAT - situated in the site of Institute National Polytechnic (Toulouse INP) &
b) ICA - situated in the site of Ecole des Mines Albi (IMT Albi)
